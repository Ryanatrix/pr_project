# Bayesian MRF segmentation of brain tumours (BRATS) with MCMC

Probabilistic reasoning course project. Hierarchical hidden-MRF segmentation,
Gibbs sampling, uncertainty maps.

## Data
Not included in the repo. Download BRATS 2013 (Image_Data: HG, LG) and place it at
`data/BRATS2013/Image_Data/`. License: CC BY-NC 3.0.

## Setup
pip install -r requirements.txt

## Run
python experiments/<script>.py
